# go-parts documentation

go-parts is a single-binary, embedded-storage electronics parts database. This directory is
the documentation tree. [Project README](../README.md) · [Constitution](../CLAUDE.md).

## What lives where

| Path | For | Holds |
|---|---|---|
| [`guide/`](guide/) | end-users | install, quickstart, usage, CLI reference |
| [`reference/`](reference/) | users + contributors | architecture, data model, config, API |
| [`internals/`](internals/) | contributors | the PRD, style guide — what we're building and why |
| [`development/`](development/) | contributors | how we work: build/test, review process, memory substrate |

Decisions (the architectural "why this, not that") are **not** files here — they live in the
go-parts memory vault and are recalled, not browsed. The PRD (`internals/`) holds the overall
design rationale.

This is plain Markdown — browse it on GitHub. There is no static-site build.
